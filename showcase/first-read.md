# Inspect a computer without running a shell command

Before starting a build or checking a service, a small program can answer a simpler question:
**which of my computers is online, and what kind of computer is it?**

The SDK's first-read example finds an online computer and prints its operating system,
architecture and CPU count. It needs read access. You can try the connection before granting
command execution, then build the workflow you actually need.

Use the [complete quickstart](../docs/quickstart.md) for setup and the
[executable examples](../examples/README.md) for the TypeScript and Python programs.
Your result describes your selected computer; choose an explicit machine when the target matters.
